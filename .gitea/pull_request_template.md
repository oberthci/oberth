

## Contract review

Answer each question in one line; `none` is a valid answer.

1. Which function does this add, strengthen or remove?
2. Which contradiction did you hit, and which separation did you choose?
3. What did you copy instead of import?
4. What did you claim that is not measured?
5. What did you add that has no sunset?

A wrong answer to question 3, 4 or 5 blocks promotion.
