used for the sealed Helm kubeconfig. All impersonation fields and caller
transport/auth/exec/proxy/dial hooks refuse. Bounded literal CA and one client
credential replace file paths; an internal no-proxy function blocks ambient
proxy input. Running-installer verification hashes a descriptor opened through
the kernel `/proc/self/exe` link, preserving the running inode across replacement.

`adoptWatchTunnelReceipt` routes prepared v2 to `executeWatchRecovery`, which
checks `recoveryOrigin` before entering unexported `applyWatchRecovery` with
`requireRecoveryGuard`. The engine uses the same four typed API endpoints for
initial SSA, the metadata JSONPatch and final SSA. `InstallOberth` preserves the
returned public receipt, calls `requireWatchRecoveryBeforeHelm`, then uses the
ordinary `OberthHelmArgs` and pinned runner. Actual Helm receives no ownership,
force, replacement or client-side bypass flag. V1 keeps its existing deployed
guard. There is no public API, CLI flag or runtime environment origin bypass.

canonical merged public values JSON (sorted object keys, no trailing newline).

`auditDomain`, and `witnessKeyInfo`, and a complete `argo.goProxy` namespace with
`modulePrefix`, `repositoryPrefix`, `upstream`, and `organization`. The daemon's

conflicting namespace values in multiple files refuse. Existing deployment
identifiers are supplied by the administrator outside the source checkout.

whole-group omission, conflicting files and source-path replacement.
