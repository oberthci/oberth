# v0.21.8

## R2-3 through R2-7 — Plugin install and repository polish

- Keep pre-install URL/CA settings optional with empty defaults, explain unset
  notices up front, and document CLAUDE_CONFIG_DIR-aware identity paths.
- Probe planned client endpoints before the install review and propose local
  k3d/Docker published ports; ambiguous, unrelated and remote-daemon bindings
  are refused as proposals. Every cluster keeps the same review gate.
- Bind each repository's SSH command to the selected installation and pinned
  host key, using authenticated server repository paths and exact printed push
  URLs. Global Oberth SSH aliases no longer select a push destination.
- Support home-relative upstream paths and custom SSH forges with manual key
  registration and authoritative host pins.
- Explain that assisted fixes need a committed, unassisted green run before
  promotion, with a helper option for that one unassisted push.
