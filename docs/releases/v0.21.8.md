# v0.21.8

## R2-2 — Advertised endpoints and readiness-first verification

- Install saves advertised client host and port choices in Helm-owned Service
  annotations. Verify reuses them without client flags; explicit flags override.
- `/readyz` and in-pod `oberth admin readiness` expose fixed, secret-free reason
  codes. An unready deployment blocks dependent HTTPS and SSH checks with its
  readiness cause instead of network or certificate remedies.
- Dry runs allow existing certificate and secrets output paths, preserve their
  contents and avoid reading recovery credentials.
