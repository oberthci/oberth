# v0.22.6

## Upgrade

Upgrading an install made by v0.22.4 or earlier to v0.22.5 failed chart
validation on two retired controller-profile values
(`argo.controllerProfile`, `argo.controllerProfileConfigMap`) that every
installer-made install has in its stored configuration. No change was applied
by the failed upgrade.

`oberth upgrade` now drops those two stored values, as it already did for the
retired Transit values, and names them in its output. Operator-set values are
kept unchanged.

`oberth upgrade --dry-run` now validates the cleaned stored values against the
target chart, with the same check the upgrade itself runs, so a dry run fails
wherever the upgrade would.

Upgrade from v0.22.4 directly to v0.22.6. Everything in the v0.22.5 notes
applies, including: all secret approvals are cleared; re-approve.
