# Oberth v0.17.68

- Upgrade waits retry transient idle-probe failures with bounded backoff and
  retain useful diagnostics. A dedicated read-only pool keeps idle snapshots
  fresh during writer contention; missing or expired snapshots still refuse
  critical-idle checks. See [restart handover](../restart-handover.md).
- Audit mutation gates retry concurrent head advances within their overall
  deadline. Changed proofs, tampering and head regressions still fail
  immediately. MCP clients receive a retryable unavailable response when
  contention exhausts that deadline. See
  [audit verification](../audit-verification-cache.md).
- Run-log requests return empty logs for steps that never executed, including
  preserved execution diagnostics. Pending logs remain pending, while invalid
  run and step identifiers still return errors.
- CI runs each package in one race group and uses controlled clocks for long
  waits, reducing duplicate work and elapsed test time.

This update adds no database migration or required configuration values.
Release binaries and packaged charts continue to derive their versions from
the release tag.
