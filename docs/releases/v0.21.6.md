## #1536 — verify encrypted install recovery with age

- Add an integration regression using real `age` and `age-keygen` when available. It checks that an interrupted install saves an encrypted, owner-only recovery snapshot, that recovery and unseal decrypt it through an inherited identity descriptor, and that failed unseal, incorrect identities and truncated ciphertext do not disclose credentials.

- Secret-store test fixtures also withhold command payloads and stdin on unexpected-command failures.
