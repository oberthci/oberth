# Oberth v0.17.84 candidate

This candidate builds on the [v0.17.83 candidate](v0.17.83.md), including
its schema-48 migration lineage and shared source/artifact PVC correction.
The chart version is 0.17.84 and its application version is v0.17.84.
Independent CI and live release qualification remain required.

## Credential admission

Uncredentialed branch runs can be admitted while secret reconciliation or
grant loading is unavailable. They receive an empty secret approval set and
do not read secret grants. Release runs, durable credential flags and
credentials found in resolved Workflow documents still require healthy
reconciliation and approved secret access. Inline and pinned fragment
credentials participate in the same classification.

## Upgrade rehearsal

The repository includes a published-to-candidate upgrade harness in
`hack/upgrade-e2e/`. It accepts an explicit published version and ordered
candidate refs, checks migration ledger preservation with target-version
readers, and exercises queue priority admission after each checkpoint.
See its README for execution requirements and the limits of its suspended
Workflow fixture. Inclusion of the harness does not establish a successful
rehearsal for this candidate.

Back up the database before upgrading. Helm rollback does not undo database
migrations. The v0.17.83 capability, namespace audit and retirement
prerequisites continue to apply.
