# v0.22.3

## Granted resource annotations

Granted resource manifests now refuse nonempty `annotations` maps only under
object `metadata` or `podMetadata`, including nested templates, list entries and
case-variant spellings. Custom fields such as `spec.secretTemplate.annotations`
and Service annotation fields pass through unchanged. Reserved label rules,
native label selectors and metric label lists retain their existing behavior.

Operators are responsible for what a granted controller copies onto Pods.
Constrain those fields with a ValidatingAdmissionPolicy on the granted kind;
see [operator controls](../workflow-capabilities.md#operator-controls-for-resource-templates).
