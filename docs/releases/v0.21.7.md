## #1539 — Control-plane recovery under CI saturation

- The server, managed Argo controller and managed OpenBao share a chart-owned priority above pipeline workloads.
- Pipeline Pods and helpers use a lower, non-preempting class; repository workflows cannot request control-plane priority.
- The installer establishes Helm-owned classes before dependency installation and refuses conflicting class ownership or policy.
- Rendering and admission tests cover both tiers and dependency chart values. Live saturation/restart timing is verified by the coordinator.
