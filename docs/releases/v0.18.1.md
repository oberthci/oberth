# v0.18.1 release candidate

This candidate builds on v0.18.0. It adds one read-only fact to the
repository list: how many non-default branches each repository's mirror holds.

**MCP tools: 90 → 90.** No tool is added or removed. `repo_list` rows and
`/api/repos` rows gain `non_default_branches` (integer; absent when the count
is unknown).

## Non-default branch count (#1508)

- **What is counted.** Branches under `refs/heads/` other than the branch the
  mirror's `HEAD` names. Oberth's own refs (`refs/oberth/*`), replace refs,
  remote-tracking refs and tags are not branches and are not counted. A mirror
  with an unborn or detached `HEAD` counts every branch.
- **Cost.** Counts are read from the local mirror and cached per mirror for
  one minute, so a dashboard render or `repo_list` call does not walk refs per
  request. A mirror under a long fetch may show no count until the fetch
  ends. Archived repositories stay hidden by default and are not walked;
  `archived=only` shows their counts.
- **Dashboard.** `/repos` shows the count as muted `+N` text under the default
  branch, only when it is above zero, with a "N non-default branches" title.
  There is no branch view, so it is not a link. No status, badge or layout was
  added.

## Upgrading from 0.18.0

No values, flags or schema change. Roll back to v0.18.0 freely.
