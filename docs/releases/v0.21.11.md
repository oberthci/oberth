# v0.21.11

## Bootstrap contract cell (#1533)

Branch and release rest-test Pods now run a blocking deterministic bootstrap
cell before their race tests. It covers verified plugin fetches, JSON plan and
context resolution against fixtures, answers/recovery validation, pinned CA
settings merge and scanning of captured output, with current mTLS, invite and
add-repo contracts. No VM or nested cluster is required.

The fresh-machine script separately provisions pinned, verified k3s and Helm,
uses certificate enrollment, and retains the held-run and reboot/unseal path.
It remains outside CI and awaits a disposable VM runner with authenticated
post-reboot results; full bootstrap acceptance is not claimed.
See [bootstrap acceptance](../bootstrap-cell.md).
