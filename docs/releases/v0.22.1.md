# v0.22.1 installer follow-ups

A successful NetworkPolicy measurement from `install --plan` can be reused
once by an install for five minutes. A private receipt binds the verified
cluster and pipeline namespace identity, labels, nodes and probe configuration.
Other preflight checks still run. Missing, expired, failed or mismatched proof
runs the complete live measurement; fresh installs retain the enforcement gate.

Installing a source chart with a versioned candidate binary stamps a private
chart copy with the candidate version (or explicit `--chart-version`). Helm
release metadata and notes use that version; the source checkout is unchanged.
