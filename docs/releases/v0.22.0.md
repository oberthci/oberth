# v0.22.0

## Plugin installation

- IP-only and load-balancer endpoints get a proposed DNS name, exact hosts/DNS
  instructions and a name re-probe before installation continues (#1544).
- Managed clusters can use a reviewed LoadBalancer Service. Address discovery
  waits within a fixed bound and retains the approved hostname and client ports;
  the wait creates no Service before install Review (#1545).
- Missing kind port mappings produce a complete loopback mapping configuration
  and guarded create command using a separate new kubeconfig. Existing files,
  symlinks and the selected cluster are preserved (#1546).
