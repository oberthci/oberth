# v0.22.0

- Reduce background upstream, Kubernetes and secret-store diagnostics to sixty-second defaults with configurable intervals. Share SSH probes across organizations using the same endpoint and credentials, back off on failures, and require three consecutive upstream failures before reporting unavailable. Status retains check times and last errors without gating Git operations.
- Skip startup retries for interrupted promotions whose repository, source, target and train were already delivered by another promotion. A concurrent delivery is handled quietly without hiding other retry failures.
